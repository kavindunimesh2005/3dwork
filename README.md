# The Lost Kingdom — QR 3D Digital Story Prototype

A React 19 + Three.js prototype for a QR-to-3D storytelling experience.

## Run

```bash
npm install
npm run dev
```

Open the local Vite URL on desktop or mobile.

## Included in this prototype

- QR code that points to the current story URL
- Cinematic landing screen
- Interactive Three.js 3D scene
- Orbit/zoom controls
- Chapter navigation
- Character dialogue UI
- AR mode placeholder for the next implementation phase
- Responsive mobile layout
